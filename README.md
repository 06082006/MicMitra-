# 🎙️ MicMitra

**MicMitra** is a student-led initiative focused on helping students build confidence in **public speaking, communication, presentations, and peer learning**.

### ✨ Features

* 🎤 Public Speaking & Communication
* 🤝 Peer Learning
* 📚 Student Workshops & Activities
* 🚀 Confidence Building
